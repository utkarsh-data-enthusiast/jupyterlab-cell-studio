# Contributing

Contributions, security fixes, tests and translations are welcome under the MIT license.

1. Fork the project, create a focused branch and include tests for changes.
2. `npm install && npm run test:sections && npm run check && npm run build`.
3. Test manually against the supported JupyterLab/kernel versions using `docs/RELEASE.md`.
4. Do not add telemetry, advertising, user profiling, auto-upload of notebook data, or external runtime dependencies.
5. Document behavioral changes in CHANGELOG.md and keep the privacy policy accurate.

All contributors retain their copyrights and license their contributions under MIT when submitting a pull request.
